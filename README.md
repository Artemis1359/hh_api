# hh_api

## 📄 Описание

**`hh_api`** — сервис для работы с API [HeadHunter](https://hh.ru), который позволяет автоматизировать поиск и обработку резюме кандидатов.

Сервис поддерживает получение резюме по **поисковым ссылкам**, которые можно сгенерировать на hh.ru при помощи расширенного поиска. Это особенно удобно для рекрутеров и заказчиков, которым нужно регулярно находить подходящих соискателей.

## 🔧 Возможности

- Получение списка кандидатов по поисковым ссылкам.
- Возможность интеграции с другими системами через брокеры сообщений (например, Kafka или RabbitMQ).
- Поддержка автоматического добавления новых кандидатов в систему.
- Возможность ручного запуска поиска кандидатов при необходимости.
- Получение контактной информации соискателя (при наличии оплаченного доступа на стороне HeadHunter).

## 🧩 Использование

Проект задуман как модуль, который можно интегрировать в большую рекрутинговую систему. Возможные сценарии использования:

- Автоматическое пополнение базы кандидатов по заданным критериям.
- Получение контактов интересующих соискателей (при наличии доступа).
- Интеграция с микросервисной архитектурой с помощью брокеров сообщений.

## 🚧 Статус

На данный момент проект находится в активной разработке. Некоторые функции могут быть недоступны или нестабильны.
